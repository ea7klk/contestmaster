# Master data sources and nightly refresh

This catalog recommends public primary sources for Contestmaster's reusable geographic and callsign reference data. These datasets serve different contest rule systems and should be kept in separate tables. “Public source” describes access to the material; it does not automatically grant permission to copy, transform, or redistribute it. Confirm source terms before enabling an importer for a public service.

### Source selection conclusions

- CQ and amateur ITU zone definitions are published by different authorities and must never share one zone table or numeric namespace.
- Big CTY is a useful, regularly refreshed operational lookup for callsign prefixes, DXCC entity, CQ zone, and ITU zone. Use it to seed or cross-check mappings, while published contest rules and the relevant zone authorities govern adjudication.
- IARU Region membership and ITU Radio Region geography are related, but model them separately and keep their correspondence explicit.
- “Country” is too imprecise for contest scoring. A master entity should carry a namespace and authority code so DXCC entities, sovereign countries, territories, and contest-specific entities are not collapsed together.
- ITU Appendix 42 allocates international call-sign series to administrations. It does not by itself describe every domestic callsign pattern, issued station, contest prefix, or call district.
- Call districts must be maintained per administration. Some districts may be inferred from a callsign only under a jurisdiction's published plan; in other cases the station's operating location is required.
- Every row or assignment should retain source/version provenance and effective dates. Keep removed items for historical log interpretation and reproducible score runs.

## Nightly refresh behavior

Schedule a master-data source check every night. For each configured source:

1. Fetch the official landing page or data feed, honoring published access limits and terms. Use ETag/Last-Modified where supported; otherwise compare a normalized content checksum or publication/version date.
2. Store the response metadata and raw artifact when permitted: source key and URL, retrieval timestamp, published edition/date, checksum, parser version, and license/use note.
3. Parse to a candidate version and validate required keys, record counts, uniqueness, cross-table references, effective dates, and expected coverage.
4. Keep the active version if retrieval, parsing, validation, licensing, or completeness checks fail. Record the failure and alert operators.
5. Activate only a complete valid version. Material changes to human-authored geographic definitions or sources that require interpretation should wait for review; a nightly check can discover changes without assigning zones incorrectly.
6. Retain prior versions and associate any score run that depends on master data with the version or immutable snapshot used for adjudication.

The nightly schedule means each enabled source is checked every night; it does not mean every source is guaranteed to publish new data nightly. Static authoritative references may be unchanged for years. A source with restrictive terms must stay disabled for copying/redistribution until the appropriate permission is in place.

## References

- [ITU Radio Regulations 2024, Volume 1: Article 19](https://search.itu.int/history/HistoryDigitalCollectionDocLibrary/1.49.48.en.101.pdf) states the relationship between station callsigns and the international series assigned to administrations in Appendix 42.
- [FCC ULS Public Access Files guide](https://wireless.fcc.gov/uls/documentation/pa_intro24.pdf) describes complete and daily license/application data files and their pipe-delimited structure.
- [ARRL DXCC Rules](https://www.arrl.org/dxcc-rules) explains that DXCC entities are discrete geographic or political entities for that award, not necessarily conventional countries.
- [UN Statistics Division M49 overview](https://unstats.un.org/unsd/methodology/m49/overview) provides country-or-area codes and statistical groupings; these are a geographic reference, not contest multipliers.
- [IARU Region 1 HF Manager's Handbook v9](https://www.iaru-r1.org/wp-content/uploads/2019/08/hf_managers_handbook_v9.pdf) identifies its edition date and non-commercial copying terms on its cover page.
- [WSJT-X user guide 2.7.0](https://wsjt.sourceforge.io/wsjtx-doc/wsjtx-main-2.7.0.pdf) documents `cty.dat` use and points to Big CTY for updated files; the [WSJT-X `cty.dat` copyright notice](https://github.com/WSJTX/wsjtx/blob/master/cty.dat_copyright.txt) contains the separate license notice for that data file.
