# Participant guide

Contestmaster accepts guest log submissions; you do not need an account. Use the contest list to select an open contest, check its submission deadline and supported log format, then upload your file. Keep the receipt token shown after a successful upload. It lets you return to that entry to view its import summary, correct contact details, or submit a revised log. The token is a secret: save it somewhere private and do not share it.

Registered participants can request a short-lived email magic link after verifying their email address. A link grants access only to entries associated with that verified identity and can be used once before expiry. A participant account is separate from global-administrator and contest-manager accounts.

Upload a log in one of the formats enabled for the contest: UTF-8 Cabrillo 2.0/3.0 or text ADI/ADIF (`.adi`/`.adif`). Some digital contests require ADIF; others permit ADIF or Cabrillo. The upload page shows the selected contest's accepted formats. See [supported formats](../formats/README.md) for required fields and limits. The upload page reports parser errors by source line. Correct those items and upload again; rejected files are not partially accepted. An accepted revision preserves its prior version and original file so contest scoring can be reproduced. If the contest manager enabled automatic recalculation, an accepted new revision may cause a new score run.

Public contest results and standings are available without sign-in after the manager publishes them. Public pages show the released score summary and configured categories; they do not expose original log files, QSOs, email addresses, or internal review notes. The contest sponsor's published rules remain authoritative for eligibility, scoring, and deadlines.

If you lose a guest receipt token, contact the contest manager. The service stores only a token digest and cannot display the old secret again. A manager may revoke or rotate access. Do not include a receipt token, magic-link URL, or full log file in a public support request.
