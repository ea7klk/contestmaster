# Participant guide

Contestmaster accepts guest log submissions; you do not need an account. Use the contest list to select an open contest, check its submission deadline and supported log format, then upload your file. Keep the receipt token shown after a successful upload. It lets you return to that entry to view its import summary, correct contact details, or submit a revised log. The token is a secret: save it somewhere private and do not share it.

Each public contest details page starts with the contest manager's description, which supports Markdown. Below it, a plain-language overview is generated from the selected ruleset. The category summary explains entry-classification dimensions, required or optional selections, allowed choices, declaration requirements, and category dimensions that cannot be combined. It shows each category dimension as an indented bullet and includes contest-specific explanations authored for a dimension or choice. Unless contest-specific rules say otherwise, generated power descriptions assume QRP up to 5 W, Low Power up to 100 W, and High Power up to the applicable legal limit; sponsor rules define the measurement point and take precedence. Other summaries cover exchange fields, operating eligibility, duplicate handling, scoring, and accepted log formats where those rules are present. For each enabled Cabrillo or ADIF format, it lists the importer's required headers or QSO fields and the contest's configured limits, such as accepted bands, modes, and required exchange values. Required Cabrillo details appear as an indented bullet list. When the configured rules allow a safe, valid sample to be derived, Cabrillo contests also show a monospace example file containing two QSO lines. This generated overview and sample are conveniences and may be imprecise; the contest sponsor's official published rules remain authoritative. The English version of the generated description remains authoritative when translations differ.

Registered participants can request a short-lived email magic link after verifying their email address. A link grants access only to entries associated with that verified identity and can be used once before expiry. A participant account is separate from global-administrator and contest-manager accounts.

Upload a log in one of the formats enabled for the contest's selected ruleset: UTF-8 Cabrillo 2.0/3.0 or text ADI/ADIF (`.adi`/`.adif`). Some digital contests require ADIF; others permit ADIF or Cabrillo. The upload and entry-management pages filter the file chooser to the selected contest's accepted formats. This filter is a convenience; the API rejects a format that the ruleset does not enable, even if a client bypasses the filter. Contests without a ruleset or without a supported format cannot receive uploads. See [supported formats](../formats/README.md) for required fields and limits. The upload page reports parser errors by source line. Correct those items and upload again; rejected files are not partially accepted. An accepted revision preserves its prior version and original file so contest scoring can be reproduced. If the contest manager enabled automatic recalculation, an accepted new revision may cause a new score run.

Public contest results and standings are available without sign-in after the manager publishes them. Public pages show the released score summary and configured categories; they do not expose original log files, QSOs, email addresses, or internal review notes. The contest sponsor's published rules remain authoritative for eligibility, scoring, and deadlines.

If you lose a guest receipt token, contact the contest manager. The service stores only a token digest and cannot display the old secret again. A manager may revoke or rotate access. Do not include a receipt token, magic-link URL, or full log file in a public support request.
